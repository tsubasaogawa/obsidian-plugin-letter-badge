# Letter Badge

An Obsidian plugin that shows a one-letter badge on the Windows taskbar button, so you can tell vaults apart at a glance.

The badge is drawn by the plugin, so you don't need to prepare an icon file.

## Features

- Shows a letter badge as a Windows taskbar overlay icon.
- Uses the first letter of the vault name by default.
- Lets you choose the letter, background color, and letter size.

## Usage

1. Install and enable the plugin.
2. Go to **Settings** > **Letter Badge**.
3. Set the **Letter**, **Background color**, and **Letter size**.

## Limitations

- Windows only. Overlay icons are not supported on other platforms.
- Pop-out windows don't get a badge.
